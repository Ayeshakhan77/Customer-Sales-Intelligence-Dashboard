# Customer Sales Intelligence Dashboard

## 📌 Project Overview
An end-to-end data analytics project analyzing customer 
buying behavior and revenue patterns using Python, 
PostgreSQL, and Power BI.

## 🎯 Business Problem
How do customers buy? Which segments drive revenue? 
What patterns predict future sales?

## 🔧 Tools & Technologies
- Python (Pandas, NumPy) — Data Cleaning
- PostgreSQL — Business Questions via SQL
- Power BI — Interactive Dashboard

## 📊 Dataset
- 3,900+ rows of customer sales data
- Cleaned and processed from raw format

## 🔍 Process
1. **Data Cleaning** — Handled nulls, duplicates, 
   data types in Jupyter Notebook
2. **SQL Analysis** — Answered 5+ business questions 
   using PostgreSQL queries
3. **Dashboard** — Built interactive Power BI report 
   showing customer segments, revenue trends, 
   buying patterns
